## Why JsonDB

<CardGrid>
  <Card title="Plain JSON on disk" icon="seti:json">
    One readable file per collection, one line per document. No server, no binary format, nothing to install.
  </Card>
  <Card title="XPath queries" icon="magnifier">
    Find, sort, slice, count and update documents with [JXPath](/guides/queries/) expressions over your own classes.
  </Card>
  <Card title="Field encryption" icon="seti:lock">
    Mark a field [`@Secret`](/guides/encryption/) and it's encrypted with AES-GCM before it reaches the disk.
  </Card>
  <Card title="Schema versions" icon="random">
    [Rename, add and remove](/guides/schema-versions/) fields safely. Migrations that would lose data are refused.
  </Card>
  <Card title="Backup and restore" icon="download">
    [Zip](/guides/backup-restore/) the whole database in one call, and restore it by replacing or merging.
  </Card>
  <Card title="Runs anywhere Java runs" icon="rocket">
    Java 8 and later, [Android API 26+ and OSGi](/guides/android-osgi/). Thread-safe and `AutoCloseable`.
  </Card>
</CardGrid>
